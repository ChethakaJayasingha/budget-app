# Budget

A tiny dark-mode budget tracker for iPhone. Log credits (+) and debits (−),
see your running balance, and scroll through your statement history.

Plain HTML/CSS/JS, no build step. Data stays on the phone (localStorage);
use **Export backup** on the history screen to keep a copy.

## Install on iPhone

1. Open https://chethakajayasingha.github.io/budget-app/ in **Safari**.
2. Tap **Share** → **Add to Home Screen**.
3. Launch it from the home-screen icon (data entered in a Safari tab is kept separately).

## Run locally

```sh
python3 -m http.server 8000
```
